Mac（M 芯片）部署脚本

git clone https://github.com/jiutinglifeng/airbeep-calltone-research cd airbeep-calltone-research python3 -m venv .venv && source .venv/bin/activate pip install "pymobiledevice3==11.26.1" brew install ffmpeg
部署完成后，按本页下方「操作检查卡」逐步执行：手动检查 → 开发者模式 → 执行 AirBeep → 通话测试 → 重启后测试 → 恢复原生。

Win 系统部署脚本

git clone https://github.com/jiutinglifeng/airbeep-calltone-research cd airbeep-calltone-research python -m venv .venv && .venv\Scripts\activate pip install "pymobiledevice3==11.26.1" winget install ffmpeg winget install AppleiTunes
Windows 路线用 source-patched/ 下的脚本（不要用 macos-port）。部署完成后，按本页下方「操作检查卡」逐步执行。

📖 小科普 · 每一步在做什么
  • ios支持版本：到 GitHub 仓库看 README 的 Requirements 支持区间，确认你的系统版本在列——不在列就千万别升级系统。
  • 开发者模式：先连一次电脑让入口出现，再到「设置 → 隐私与安全性 → 开发者模式」打开开关 → 点「重新启动」→ 开机后点「打开」并输入锁屏密码。
    爱思助手路线：爱思助手 → app 上方「工具箱」→ 虚拟定位 → 任意尝试定位 → 手机进入「设置 → 隐私与安全性 → 开发者模式」。
  • 执行AirBeep：打开 AirBeep 拨动开关即把录音提示音换成等长静音，操作中别退出 app，替换完会自动留存原件备份。
  • 自行通话测试：拨一通电话并开启录音，听听起止提示音是否已经消失（静音成功）。
  • 重启后测试：重启手机后再打一通电话，确认静音在重启后没有失效。
  • 恢复原生方案：在 AirBeep 里点「恢复」，即可从自动备份一键还原系统原始提示音，随时可逆。
